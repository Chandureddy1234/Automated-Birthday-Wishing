# Automated Birthday Wisher

A Python application that automatically sends birthday emails to contacts from a CSV file.


## Features
- 📅 Reads birthdays from CSV file
- ✉️ Sends personalized emails automatically
- 🔒 Secure credential management
- ⏰ Daily automated checks
